# 002-UI界面（美术设计）

本文件夹集中整理 LINK 项目现有的界面视觉参考、页面素材与 UI 说明，方便后续制作/补齐正式页面原型。

## 目录

- `01-页面原型与参考`：当前内部页面素材拼图预览。它是素材总览，不是整页截图原型。
- `02-品牌与首页登录`：品牌图、首页背景图和首页/登录视频。
- `03-课堂与学生素材`：虚拟学生状态图与课堂总结插图。
- `04-课程与资源素材`：课程及资源库封面图。
- `05-设计说明`：UI 交接说明、产品需求及课堂/UI 实现说明。

## 当前缺项

仓库中目前未发现 Figma/Sketch 等可编辑设计源文件，也没有工作台、课程中心、模拟课堂等页面的整页设计稿截图。`01-页面原型与参考/内部页面素材总览.png` 仅用于快速查看现有素材。正式原型可在此文件夹补充，建议按 `页面名/桌面端.png`、`页面名/移动端.png` 及对应源文件归档。

## 素材来源

本目录中的视觉素材均从 `frontend/public` 复制，设计说明从 `docs` 复制；归档副本与运行时原文件分开，修改本目录内容不会自动改变线上页面。
