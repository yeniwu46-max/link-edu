# 紧凑工作台、像素动作与阿贝贝老师 · 2026-10-22

本记录对应最新实现，替代前一轮记录中的“大标题、滚动纵向坐席、单姿态动作”描述。原版 UI、旧图集、三视图与历史设计稿继续保留。

## 页面与角色

- 备课桌版首页使用 56px 问候工具行（桌面 28px / 手机 24px）。本周训练合并为摘要，训练、入口、反馈、轨迹填满剩余空间。长反馈只展示三行，点击查看原详情。长课程名与人物预览分别占位。
- 七个子页面一级标题对读屏保留，视觉大标题及重复面包屑移除；首页动态时间与姓名保留。原版界面切换后恢复原有可见标题。
- 课程桌面铺满导航外工作区。十个物件、标签和高亮共用坐标变换，背景延展补齐不同比例。点击在中央弹窗选择真实课程，支持来源、慕课外链、进度、训练跳转、目录、搜索、深链接、图片失败后的文字入口。
- 弹窗正文独立滚动，关闭和训练按钮保持可见；Escape、遮罩、Tab 循环与焦点返回已检查。普通进入不自动打开。
- 对话布局桌面使用 240–300px 三等分坐席，手机为顶部三人横排。控制栏保持可见，小窗跨区拖动、方向键/Home、全屏与窗口变化后限制边界。
- v2 图集是实际运行的透明像素序列帧：瞌睡 8 帧、疑惑 8 帧、拿笔/书写/放笔各 4 帧、起立 8 帧；坐下逆序复用起立 8 帧，短发言只逆转已完成部分。书写循环三次后放笔。站姿嘴型读取实际播放音量。
- 10fps 动作时间轴、最高 30fps 画布；错开空闲动作，同一时刻最多一人瞌睡。重要课堂状态优先，动作不写入教学证据。隐藏暂停，卸载释放 ImageBitmap/观察器/帧循环，失败回退到 v1 角色素材。
- 新图集位于 `frontend/public/assets/characters/pixel/v2/`，每人约 2.45 MB；旧 v1 图集未覆盖。manifest 保存动作清单及实际帧区域；`scripts/inspect_pixel_registration.py` 只分析透明间隙生成区域数据，不改写图片。透明轮廓脚底锚点用于统一落地位置。
- 图集由内置 image_gen 生成；提示词与采用版本记录见 [v2 提示词](design/20261022/pixel/v2-final-prompts.json)。三视图仍是设计参考，下面截图和视频才是运行效果。

## 学生互动与助手

现有课堂 WebSocket 新增：

```json
{"type":"student_interact","student_id":"ming","event_id":"唯一请求 ID"}
{"type":"cancel_student_interact","event_id":"另一唯一 ID"}
```

- 已举手点击仍点名；其他学生点击按各 50% 概率选择提问/合理反驳，调用现有真实模型流式管线。
- 单一等待槽：同一待触发学生不叠加，另一人替换，界面可取消。等待现有回答、教师讲话及语音结束静默期；执行时读取最新上下文。人工邀请优先于尚未获邀的自动举手。
- 未开课、暂停、断线和结束不触发；暂停/断线/结束清空等待槽；失败不自动重试，提示重新点击学生。既有事件 ID 去重仍有效。
- 正式学生事件附加 `trigger: manual_click`、`interaction_kind`、`request_id` 和 `generation_id`；不伪造教师转写，不增加自主提问计数。评课提示明确区分人工邀请和自主发起。没有新增数据库表。
- 连续对话按事件、生成和回复 ID 归并；覆盖正式事件先到、迟到事件、重复投递及中断草稿，草稿不成为正式证据。
- 所有助手身份文案改为“阿贝贝老师”。聊天可切换温暖/冷静，浏览器保存，缺省温暖。LINK 品牌及接口路径保留。
- `POST /assistant/ticket` 接受可选 `style: warm | calm`；非法值返回 400。连接可发送风格更新；回答启动时冻结该轮风格，更新从下一轮生效，不取消当前回答或重开麦克风。语音朗读同一风格文本，音色保持原值。
