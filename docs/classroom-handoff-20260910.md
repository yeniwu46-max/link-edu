### 设计约束

- DeepEval 只在独立评测环境安装；不把评测依赖加入生产启动环境。不引入 OpenMAIC 的完整课堂运行框架，也未接入 Promptfoo 或观测平台。
- 默认 `check` 不联网、不调用模型。付费 `replay/generate` 必须显式 `--paid`、配置单价和本次费用上限；Judge 使用独立 `EVAL_JUDGE_*`，不回退到生产密钥。
- 评测业务数据在临时 SQLite；生成侧仅沿用既有测试账户预算账本。语义失败、Judge 错误、不适用和未评估分开报告，尚未作为自动发布门禁。
- 动作只解释可观察几何和行为，不做人脸识别、情绪或心理推断；观察建议不是自动加减分规则。默认本地教师入镜检查不等于课堂背景语义识别。
- 摄像头是正式授课必需条件，但浏览器授权不能绕过。单独预览只开视频，不开麦、不创建课堂、不开始计时、不调用付费 AI。
- “结束并评课”有前后端 10 秒门槛；“暂停设备采集”不受这项门槛限制，随时可用。判断是否生成报告另看证据完整性。
- 全屏中固定视频、学生区和操作栏尺寸，保留稳定组件身份；关闭全屏中的设置或记录窗口不应顺带退出全屏。

## 2. HTTP 500 的定位与恢复

故障事实：前端 `127.0.0.1:5188` 正在监听，`frontend/.env.local` 的 `LINK_BACKEND_URL` 指向 `http://127.0.0.1:5001`，但后端没有运行，代理请求返回 HTTP 500。

处理分为两层：

1. 页面层：读取状态超时为 10 秒；读取失败与加载中分开保存、展示，不再无限显示“读取中”。按钮下方列出授权、设备忙、服务配置、价格和预算等全部阻止原因；支持重新读取状态和查看设置。过期缓存不会静默解锁启动。
2. 运行层：验证本机 Python 3.14 后端依赖后，使用现有 `scripts/start-classroom.ps1` 启动 5001 后端，保留已有前端进程。本次启动进程设置 `SEED_ON_STARTUP=false`，避免重跑演示种子；未改本地密钥或费用配置。

恢复后实际核验：

- 直连 `http://127.0.0.1:5001/api/health`：200。
- 经前端代理 `http://127.0.0.1:5188/api/health`：200。
- 使用项目已有演示账号登录，随后读取 `/api/classroom/capabilities`、`/api/classroom/sessions`：200。检查过程不输出或保存登录令牌。
- 对话、ASR、TTS、视觉配置及价格确认均有效，授课预算未到停止线。
- `status=unverified` 仅说明本次后端进程没有运行独立付费探针；不等于配置失败，也不能单凭 HTTP 200 宣称所有云服务实时可用。本次恢复核验未新增付费模型或语音调用。

后端运行与 Git 推送是两回事：提交代码不会自动启动同事电脑上的服务，也不会把本机端口发布到互联网。

### 下次启动

在项目根目录，保持现有本地配置，不覆盖 `.env`：

```powershell
# 已有数据库、无需演示种子时使用；只影响当前启动进程，不改 .env 文件。
$env:SEED_ON_STARTUP = 'false'
./scripts/start-classroom.ps1 -PythonPath 'C:/Python314/python.exe'
```

其他电脑把 `PythonPath` 换成已安装后端依赖的 Python 3.10+ 路径。首次安装参照 [启动说明](classroom-runbook.md)。启动脚本不会杀掉占用端口的进程；出现占用警告时先核对服务身份、版本和代理目标，不重复启动多个共享数据库的课堂后端。

浏览器打开 `http://127.0.0.1:5188/classroom`，点击“重新读取状态”；登录已过期时重新登录，再勾选两项授权。不要为解决连接问题跳过授权、改预算或关闭 TLS 校验。

## 4. 明确未完成：录像预览与是否保存

**当前课堂只提供实时摄像头预览，没有完整音视频录制、课后录像预览和“保存／放弃录像”弹窗。** 现有结束流程收尾语音、保存事件、生成或阻止报告，然后关闭设备。不是某个录像按钮被隐藏了，也不能从事件摘要还原刚才课堂的完整录像。

下一轮应实现并验收：

1. 明确独立录制授权与范围（仅教师镜头，或包含学生、字幕的完整课堂画面），不把摄像头开启同意默认解释为录像同意。
2. 浏览器录制、教师与学生音轨处理、格式兼容、文件大小和内存上限。
3. 结束后先弹出视频预览，再由用户选择保存到本地或放弃；保存与课堂事件/报告自动入库应有清晰区分。
4. 拒绝录制、录制失败、暂停/重连、未保存离页和下载失败时给出真实状态；不伪造“保存成功”。
5. 缓冲区和对象 URL 的清理，以及合成视频/静音音轨自动化验收；真人设备与声音同步另行人工确认。

以上是待办，不属于本次已交付功能。默认不上传录像；若将来要云端保存，需另定授权、容量、保留和访问控制方案。
