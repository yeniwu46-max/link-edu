# ADR-006：VRM 数字人与独立助手会话

## 状态与日期

采用，2026-10-08。与 ADR-005 的知识库证据能力配合。

## 背景

平台已有 Three.js、课堂 ASR/LLM/TTS、预算结算和知识库。此次需要无框数字人、系统使用及教学问答，同时保持课堂录音与评分的原语义。整套外部数字人服务会增加部署、费用与两套人物控制的维护成本。

## 决策

1. 固定 `@pixiv/three-vrm` 3.5.5（MIT），本地部署 Olivia VRM0（资产元数据 CC0），记录作者、来源与哈希。使用半身镜头、紫橙灯光、标准化骨骼和基础音频幅度口型。
2. 不引入 TalkingHead 的另一套骨骼 / 表情控制；不引入 OpenAvatarChat 的整套后端。复用当前供应商和预算配置。
3. 助手采用独立会话与随机轮次 ID。JWT HTTP 接口签发 45 秒单次短期凭据，WebSocket 首帧消费，凭据不放 URL。
4. 助手不创建课堂 / 评分记录。上下文在内存中，只有用户主动保存才写原训练日志；成本预留与结算仍使用现有账本，课堂 session 为空。
5. 系统问答依据统一功能说明，教学问答检索原知识库；最终引用限制于本次来源，无依据明确说明。功能说明由后端 JSON 维护，构建前同步前端副本。
6. 开始 / 恢复课堂、关闭、退出登录、页面隐藏时终止助手语音；课堂采集中只提供文字。会话最多 5 分钟，静默 60 秒结束，播放回答不计静默。
7. 数字人按需加载；不可见暂停、减少动态静态呈现，失败回退同人物透明封面。取消和播放结束立即停止口型。
8. 新手导览使用 Vue、Teleport、VueUse；本地记录按用户和版本隔离。仅导航和展示，不授权设备、不开始授课。

## 后果

- 保持原单进程服务部署，暂不支持多 worker 间共享助手凭据或会话。
- 不保证中文音素级口型；需要音素时间戳或更复杂 TTS 对齐时另立决策。
- 隐私声明须明确音频和问题发送至当前服务商；默认不落库不等于不调用外部服务。
- 模型与后端需要成套发布；局部失败仍可使用本地 FAQ 和文字入口。
- 真实设备回声与打断、长期性能仍需实际环境验收，合成媒体结果不替代这部分。
