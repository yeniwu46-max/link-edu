# ADR-002：首发语音改用讯飞，保持课堂业务协议

## 状态

2026-09-08，用户已确认采用。替代 [ADR-001](001-evidence-based-classroom.md) 中百炼作为首发语音供应商的选择，不替代其证据、安全、单进程与预算约束。

## 背景与决策

用户已有讯飞中文识别及合成凭证，原百炼密钥未提供。新增供应商适配层，在本机显式选讯飞，不改 DeepSeek 对话和视觉，不隐式切回其他平台。

- 中文识别 v1 单请求限制60秒，以55秒滚动分段和本地能量端点检测接入长课堂。不是把10分钟音频塞进一次请求，也不是录完才转写。
- 统一语音起止、临时/最终转写、结束事件；最终结果按段排序，保留修订，不让供应商字段扩散到前端。
- 合成首先使用实际探针可用的 `xiaoyan`，允许三个学生共享系统音色。三音色不是核心闭环的硬性门槛，仍须记录限制。
- 语音按供应商分别记账；免费额度不假设无限，取消发送前可明确作废本地预留，其他未知失败保留预留。

## 后果与验证

避免重新设计登录/课堂接口，但增加分段、收尾和排序复杂度。RMS活动检测需人工噪声/耳机/外放验收；不是成熟语音分类器。ASR动态修订与队列限界已有回归测试，真实识别和合成探针已返回，但完整真人课堂尚未验收。

详细状态、接口文档和价格依据见 [讯飞联调记录](../classroom-xfyun.md)。
