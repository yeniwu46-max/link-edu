# 教师提问响应与全屏课堂修复

2026-09-09，适用 `/classroom` 模拟课堂。无需新增模型、依赖、业务 API 或数据库迁移。

后续同日更新已将镜头改为授课必需条件，字幕默认开启，设置与记录改为弹窗，并加入 10 秒及数据完整性门槛。以下定位记录保留；最新操作和测试结果以 [摄像主画面与评课数据门槛](classroom-camera-first.md) 为准。

## 已定位并修复

1. **开始后课堂连接被销毁**：开始成功会把 `?session=编号` 写入 URL，外层 `AppShell` 原以完整 URL 作为组件 key，因此重新挂载课堂，触发麦克风与 WebSocket 清理。课堂现在按路径维持组件实例；场次参数仍由原有课堂逻辑处理，其他页面的切换行为保持不变。
2. **点名被 ASR 拆段后丢失**：“小林。”与后续问题分为两段时，原先只在最后一段找名字，导致小林的回复被未点名保护拒绝。现保留尚未消费的点名，最多 15 秒、后续 2 段；换名覆盖，回复后清除，不在重连时恢复过期点名。
3. **新提问被误当邀请旧问题**：原先任何简短含学生名的发言都可能继承旧举手问题。现仅明确邀请（如“小明，你说”）继续旧问题；“小明，分母为什么是二？”重新生成回答。
4. **直接提问被静默忽略**：模型输入增加最新确认发言与 `response_required`。点名、明确问句和全班邀请回答不受主动举手等待时间限制；不合规的 `wait`、选错学生等结果显示可重试错误，而不是静默消失。不自动重试收费请求或编造回答。
5. **全屏视频跳动**：原动作观察行出现/消失导致视频高度变化，浏览器复现约 22–45px。现固定状态区、字幕区及底部学生区域，文字在内部更新/滚动，画面大小不再随检测结果变化。
6. **备用全屏偏移**：外层 `filter: blur(0px)` 为固定定位创建了包含块，使备用全屏只有父容器宽度且受滚动偏移影响。课堂页面不再保留这个滤镜；原生和备用全屏均按视口展示。

## 使用

- 正常开始课堂，对麦克风说“小林，什么是平均分？”；也支持“小林。”停顿后继续问题，或“同学们，谁能说说什么是平均分？”。语音识别须有最终转写，模型与语音服务须配置正常。
- 开启老师镜头 → 全屏放大。底部始终保留小明、小雨、小林；生成中的回复逐段进入对应气泡。最终文本校验成功后走现有 TTS 流式音频链路，按实际播放阶段显示发言状态。
- 生成失败可“重试学生回答”，播放中可“停止学生发言”。失败不伪装成功，不以文字生成完成替代播放完成。
- 勾选字幕，选择老师/老师＋学生；字幕居中，可调 16 / 20 / 28 / 36 字号及 60% / 80% / 100% 宽度，也可一键“缩小字幕”或隐藏。退出全屏恢复普通镜头窗口。
- 画质按请求保留 **1020p / 720p / 360p**，指目标画面高度；默认 720p，按 16:9 请求宽度。1020 按用户原值实现，不擅自替换为 1080。浏览器可能协商到设备支持的其他尺寸，界面显示实际分辨率；切换失败保留原选择和镜头。
- 上课音量范围 0–100%，0 为静音，仅作用于学生音频输出，不修改麦克风音量、ASR 输入或服务端合成语音。重连保留当前课堂选择，刷新页面恢复默认音量。
- 动作推理画面按原始比例限制在 640×480 范围内，避免选择高画质时把完整高分辨率帧送入三个动作模型；本地镜头显示仍用摄像头实际分辨率。

更新后请结束正在进行的旧课堂，再重启后端并刷新前端。不会自动终止用户的活动课堂，也不会修改历史报告。

## 验证

回归覆盖：拆段点名、过期/换名、旧举手问题和新提问区分、直接全班提问、模型拒答错误状态、流式草稿拼合、TTS 分块与播放完成确认、摄像头画质切换失败、音量输出路径、URL 写入后保持课堂实例。

浏览器使用隔离合成课堂，真实 Vue / WebAudio / 视频画布，mock ASR、模型、TTS 和业务网络边界。没有开启真实麦克风/摄像头，没有付费 AI 请求；音频检查使用静音 PCM。不能替代真人 ASR 准确率、外放回声与语音服务可用性验收。
