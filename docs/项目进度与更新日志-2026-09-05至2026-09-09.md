## 一、项目总体进度

临客 LINK 已从原有的“AI 微格教学演示平台”推进为可运行的“真实 AI 课堂开发版”，目前已形成以下闭环：

1. 教师进入模拟课堂并完成授权与设备准备。
2. 系统接收教师语音，生成学生回应并播放语音。
3. 前端展示学生思考、生成、等待播放和发言状态，同时记录课堂时间线、语音播放结果与动作摘要。
4. 课堂结束后，系统依据已验证的课堂事件生成 AI 评课报告。
5. 用户可以对独立 AI 评课报告继续追问；追问不会修改原报告和评分。

当前自动化回归结果：

- 后端：139 项测试通过。
- 前端：44 项测试通过。
- 前端生产构建：通过。
- 已知工程提示：主 JavaScript 包约 1.24 MB，Vite 提示后续进行代码分包优化。

## 二、按核心模块说明

### 2.1 模拟授课

#### 已完成

- 新增带登录鉴权的实时课堂入口 `/classroom`，课堂服务与原演示业务相互隔离。
- 建立课堂会话、课堂事件、知识资料、报告任务和 API 预算相关数据结构。
- 接入流式语音识别与语音合成，支持教师语音输入、学生语音输出和最终转写。
- 接入模型驱动的学生对话，支持点名回答、主动发言、追问和打断等课堂互动。
- 学生回复采用可取消的流式生成状态：思考中、生成中、等待播放、发言中、已取消和失败。
- 生成中的学生文字只作为界面预览；完整结构校验通过后，才写入正式课堂事件并进入语音合成。
- 支持课堂时长、主动提问间隔、点名对象、截图数量、异常动作和语音收尾等边界控制。
- 支持课堂资料导入、知识来源记录和本地启动脚本。
- 教师发言、学生回复、语音播放、动作摘要和视觉证据均可进入课堂时间线。
- 取消、断线或教师抢话后，会丢弃迟到的生成结果和音频事件，避免旧回复污染新课堂状态。
- API 额度按“授课、视觉、测试”三类隔离；讯飞语音使用独立计费台账，保留预留、结算和异常占用记录。

#### 已验证

- 自动化测试覆盖课堂调度、多人点名、主动提问、设备生命周期、音频排队、断线、超时、预算并发和报告证据等场景。
- 隔离环境下，3 分钟真实云合成课堂链路通过。
- 直连供应商条件下，10 分钟真实云合成课堂链路通过：课堂约 601 秒，收到 15 次真实 PCM、14 次模拟完整播放、1 次打断、4 条提问事件和 38 条最终转写。

#### 当前边界

- 合成课堂通过不等于真人课堂验收完成。
- 真实麦克风、摄像头、扬声器回声、人体动作识别精度和真人连续三轮 10 分钟课堂仍待验收。
- 识别、模型回复和语音播放仍存在数秒至十余秒长尾，暂不能宣称满足稳定的 P95 延迟目标。
- 正式服务是否绕过本机代理直连供应商尚待确认；当前直连结果只能作为网络对照证据。

### 2.2 UI 设计

#### 模拟课堂 UI

- 统一为深色课堂视觉风格，补充动态背景、课堂舞台、状态提示和分区布局。
- 新增教师摄像头组件，支持镜像、全屏、骨架显示开关和重新加载。
- 身体与双手关键点模型均在浏览器本地运行；原始关键点不上传、不写入课堂历史。
- 新增字幕功能，支持“教师＋学生 / 仅教师”来源切换，以及 20、28、36 px 字号设置。
- 新增学生头像、嘴型播放反馈、状态气泡和流式文字气泡。
- 新增课堂时间线、设置面板、服务状态、额度状态和可操作的错误提示。
- 支持 320、768、1024、1440 px 等主要宽度，兼容原生全屏及回退模式，并考虑减少动画偏好。
- 摄像头授权失败不会中断语音课堂；关闭摄像头时仅释放摄像头与动作模型资源，不影响麦克风。

#### AI 评课 UI

- 将“生成 DeepSeek 评课”和“继续追问本次评课”拆分为两个独立操作区。
- 报告生成期间禁用追问；生成失败时给出可操作提示，不伪造成功状态。
- 追问区支持普通问题和近 30 天趋势问题，并标注回答所使用的范围。
- 切换历史评课时清理当前追问状态，避免不同报告之间串场。
- 证据不足的真实报告仍保留展示，并允许用户针对已有结论继续追问。
- 页面请求失败时不再静默回退到演示数据，避免把模拟内容误认为真实结果。

### 2.3 AI 评课及报告生成

#### 独立 AI 评课

- 后端接入 DeepSeek，由后端安全持有 API Key，前端不直接接触密钥。
- 基于课堂文字材料生成结构化报告，包括综合评分、六维评分、总结、问题和改进建议。
- 报告生成过程具有 `generating`、`succeeded`、`failed` 状态，失败信息可以恢复和重试。
- 已生成报告可以继续追问；追问只返回文本回答，不覆盖 `report_json`、综合分或六维评分，也不新增评课记录。
- 普通问题只读取当前报告和本次训练上下文；涉及“最近、近 30 天、进步、趋势、相比、上次”等问题时，才读取最多 10 条有效历史记录并生成紧凑趋势摘要。
- 近 30 天趋势仅使用当前用户、已成功、来源为 DeepSeek 且证据充分的报告，不发送全部原始历史报告。
- 追问提示明确把课堂材料视为不可信数据，禁止执行材料中的命令或重新计算原评分。

#### 模拟课堂报告

- 课堂结束后异步生成证据型评课报告，展示综合分、证据覆盖率、各维度理由和改进建议。
- 每个维度可关联具体课堂事件和时间点；视觉证据可在鉴权后查看截图。
- 报告展示教学依据及来源，支持外部链接和本地资料位置。
- 用户可提交补充说明并重新评课，系统保留报告版本与异议处理流程。
- 只有同一 `reply_id` 的学生语音完整播放且未失败、未打断时，学生发言才可作为评分证据。
- 若证据不足，对应维度保持空值或“暂不评分”，不使用未播放语音、低置信度动作或其他学生的记录补足证据。

#### 当前报告能力边界

- AI 报告属于辅助评价，不应替代人工教研结论。
- 合成课堂生成的分数仅用于验证链路和证据逻辑，不代表真人教学成绩。
- 真实课堂报告仍需人工检查误识别、提问相关性、追问质量和证据语义是否匹配。
