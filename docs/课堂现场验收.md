## 第一轮3分钟脚本

1. 正常讲授平均分与同一整体至少30秒，观察字幕是否持续更新。说“小明，把同一个饼平均分成两份，每份是多少？”
2. 学生举手时停顿2秒或点名。回答学生的问题，再观察是否有与问题相关的回应/追问。
3. 有意说错“随便分成两块，每块都是二分之一”，随后纠正“必须平均分”。核对学生和报告是否考虑了纠错上下文。
4. 学生发言中再次讲话打断。确认旧声音停止，不出现过时声音重新播放。
5. 结束、等待报告、点证据时间戳、提交一条具体异议。重复点击结束不得生成多份报告。

每轮记录：课堂时间戳、教师话音结束的声学时点、学生首段声音的声学时点、两者差值、是否失败。收集至少20轮，P95按排序后的第 `ceil(0.95*n)` 个值计算（nearest-rank）。失败/无声音的轮次单独计数，不把它们悄悄排除后宣称达标。浏览器 `latency` 事件仅作辅助，不等于实测声学时点。

报告分别记录“点击结束→报告可读”和“模型任务开始→完成”耗时；第一项包括转写/视觉收尾。目标分别与产品验收要求核对，不能只报较短的模型生成时间。
