## 来源与改编

- 学生继续使用已本地部署的 [Kenney Mini Characters](https://kenney.nl/assets/mini-characters)，CC0；来源文件位于 `frontend/public/assets/models/students/credits.json`。本轮加入底座、转身、近景镜头和已有点头动画的触发，并适配原状态与骨骼叠加逻辑。
- 渲染继续使用项目已有的 [Three.js](https://github.com/mrdoob/three.js)，MIT；没有新增运行时依赖。
- 书册、档案、轨道、棱镜和机器人为本项目用基础几何体构建的原创程序化模型，没有下载新的重型 GLB，也没有复制额外仓库源码。

主要实现：`InteractiveModel.vue` 处理懒加载、输入和生命周期；`interactiveModelEngine.js` 处理渲染调度；`interactiveModels.js` 定义五种模型；`ModelShowcase.vue` 提供通用旋转、展开、复位控件；`modelDrag.js` 处理拖动与点击区分。

## 性能与回退

- 学生仍共用一个 WebGL 画布和三个视口，默认约 30fps；已有低性能策略降至 20fps。
- 其他页面通常只有当前展示模型和小助手两个实例。它们仅在指针、旋转、展开或消息反馈期间绘制，过渡收敛后停止 RAF。
- 首次可见后通过动态导入和空闲调度加载；桌面像素比不超过 1.25，触屏不超过 1；不使用全屏后处理。
- 页面隐藏、组件离开可视区时暂停；卸载时清理监听、观察器、材质、几何体、纹理与 WebGL 上下文。
- 减少动态效果时使用静态姿态；手动旋转与展开直接更新静态结果。WebGL 不可用时学生回退原图片，小助手回退 SVG，其他模型回退 CSS 静态预览。
- 课堂提示气泡默认隐去，悬停或键盘聚焦小助手时出现；授课中继续只显示头像。

## 本轮验证记录

使用 Vite 开发服务器与 Codex 内置浏览器。`tests/model-pages-browser.html` 使用实际页面组件、内存路由和模拟 API，禁止后端写入和设备访问；`tests/classroom-ui-browser.html` 只生成合成视频与音频。
