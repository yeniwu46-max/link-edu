# 课堂动作与流式互动

## 使用

- 打开老师镜头后，默认显示身体及双手骨架；可关闭骨架、切换镜像、全屏放大。首次加载本地模型需要片刻。
- 字幕默认关闭。开启后可选择老师＋学生或仅老师，并使用 20／28／36px 字号；字幕显示最近更新的发言，长文字滚动保留最近三行。字号及内容偏好保存在本机，字幕开关每次进入默认关闭。
- 学生回复经历思考、生成、等待播放及发言。气泡接收真实模型增量；语音在完整结构校验后播放，嘴型只随实际播放变化。点击打断、老师开口或断线会取消过期生成。
- 生成失败可主动重试，不自动追加模型请求。语音失败仍可阅读已校验文字。

## 本地模型

运行 `node scripts/prepare-pose.mjs`，准备身体、手部模型及 WASM。运行时仅访问本站 `/models/`，不访问模型 CDN。

身体模型在主动作 Worker 内运行，手部模型在独立子 Worker 内运行；避免 MediaPipe 1.0.1 模块加载器第二次初始化时出现 `ModuleFactory not set`。最多每秒处理 10 帧，上一帧未完成时跳过新帧。

原始关键点仅用于浏览器叠层，不上传、不写入历史。后端仍只保存现有动作摘要。低置信度保留“未知”语义；坐姿仍可显示可靠上半身关键点。手部失败不会禁用身体检测，提供重新加载按钮。

## 流式协议与预算

WebSocket 保留既有完整回复及音频事件，新增 `generation_started`、`generation_student`、`reply_delta`、`generation_completed`、`generation_cancelled`、`generation_failed`。增量事件携带 `generation_id`，沿用会话编号及顺序号；前端丢弃失效生成编号。

对话适配器使用一次 SSE 请求，先读取动作与学生字段，通过点名及主动发言约束才预览文字。全文完成后校验 JSON 和字段，再生成正式课堂事件并调用现有 TTS。草稿不进入数据库或报告，原有播放完成／中断证据不变。

每个请求仅预留、结算一次，重复用量片段不重复结算。无最终用量的断流保留预留；美元用途账本和人民币语音账本保持独立。OpenAI Next 网关实际流式兼容性须用户主动联调，不以模拟测试代替真实验收。

## 验证

- `npm --prefix frontend test` 与 `npm --prefix frontend run build`。
- 在 backend 下执行 `python -m pytest tests -q --disable-warnings`。测试默认阻止未模拟的 `httpx.stream`。
- 用隔离的 Playwright CLI 会话依次运行 `scripts/qa-classroom-ui.js`、`scripts/qa-classroom-motion.js`；再运行 `scripts/qa-classroom-model.js` 检查真实本地双模型加载及空白帧检测。
- 浏览器脚本使用合成视频、关键点和回复，不使用摄像头／麦克风；页面 API 写请求被拦截。截图位于 `output/playwright/`（不提交）。
- 检查 320／768／1024／1440px、原生全屏及回退、字幕来源和字号、焦点恢复、遮挡后清屏、失败重试与减少动画偏好。

真实人体／手指精度、真实麦克风与 TTS，以及网关首字延迟需用户主动开启后验收。开发时修改后端模块需要重启单进程课堂服务，避免开启第二个后端实例。
