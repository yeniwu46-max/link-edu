## 4. 运行链路与约束

```text
麦克风 → 浏览器 PCM16 / 16 kHz → 课堂 WebSocket → 百炼 ASR（待实测）
                                                   ↓ 最终文本
本地资料 BM25 → DeepSeek 学生决策 → 举手/等待 → 回复 → 百炼 TTS（待实测）
                                                   ↓ PCM / 24 kHz
                                              排队播放 + SVG 嘴部

摄像头 ┬→ 本地 Pose Worker → 动作摘要 ──────────┐
       └→ 单独同意后抽样截图 → DeepSeek 视觉 ──┤
最终文本 + 学生交互 + 播放/打断事件 ──────────┴→ 事件存储 → 证据评课
```

- ASR 临时字幕只展示；最终文本去重后进入记忆。`session_id` 隔离场次，`event_id` 去重客户端消息，`reply_id` 排除取消后的过期声音。
- 三学生为小明（追问）、小雨（平均分/分母误解）、小林（安静、点名）。回复限制 1—2 句。角色行为是模型生成，不是对真实学生心理的测量。
- 首次主动提问至少积累 20 秒有效授课；间隔至少 45 秒，每场最多 6 次。举手后等待教师点名或至少 2 秒安静。最终输入版本与主动资格变化控制是否重新评估，避免同一句重复问。
- 教师 VAD 起音取消旧回复；客户端停掉音频队列，并分别记录已播放、失败、打断。模型生成文字不等于声音已经播放。
- Pose 最高 10 帧/秒在 Worker 内推理，服务端动作持久化最多每 2 秒一次；低置信度/无人不解释成情绪或教学质量。
- 云视觉独立同意，至少 15 秒一张、最多 40 次、单请求在途。请求次数持久化，刷新不能重置配额。默认不上传画面。
- 结束提交尾部音频，等待识别收尾与已在途视觉，再生成报告。报告任务为进程内线程；重启中断显示失败、允许人工重试，不假装持久任务已恢复。

## 5. HTTP 接口速查

统一前缀 `/api/classroom`；下列 HTTP 接口均要求原系统 JWT。场次接口校验当前账号归属，找不到或越权返回 404。POST 仅接收 JSON 对象，请求体限制 8192 字节；私有响应 `no-store`。

| 方法 / 路径 | 输入与结果 |
|---|---|
| `GET /capabilities` | 返回四服务 `model/configured/status/message`、预算、动作资源是否存在；不返回密钥。读取不触发云调用，验证状态为本进程缓存 |
| `POST /probe` | `{ "service": "dialogue" }`，可选 `vision/asr/tts`；显式付费验证，每账号同服务至少隔 30 秒；读响应 `status` 判断是否成功，不能只看 HTTP 200 |
| `POST /sessions` | `{ "mode": "full", "audio_consent": true, "camera_consent": true, "cloud_vision": false }`；语音与摄像头授权均必须为严格布尔 true。模式还支持 `fragment`。创建返回 201；已有本人 active 场次返回 200 并复用 |
| `GET /sessions` | `{items:[...]}`，本人最近 50 场 |
| `GET /sessions/<sid>` | 场次、学生、事件、报告、错误与报告版本；用于历史及报告轮询 |
| `POST /sessions/<sid>/ticket` | 返回 `ticket/expires_in=45`；票据只能消费一次，已结束场次拒绝 |
| `POST /sessions/<sid>/finish` | 幂等，202；连接在运行时先返回 `state=draining`，随后读详情观察收尾与报告状态 |
| `POST /sessions/<sid>/report` | 仅已结束场次；可传 `{ "objection": "教师异议" }`，最多保留 2000 字符；异议入事件，202 异步重评。运行中不重复创建任务 |
| `GET /sessions/<sid>/evidence/<event_id>` | 仅本场视觉事件对应的私有 JPEG；前端带 JWT 取 blob，不暴露文件系统路径 |

报告状态：`idle → running → completed / failed`。详情发现运行任务已因服务重启丢失时标记失败。没有成功响应或状态变化，不应把重复点击当作重试已完成。

## 6. WebSocket 协议速查

连接 `/api/classroom/live`，5 秒内第一帧发送 `{ "ticket": "短期票据" }`，**不要放 JWT 或票据到 URL**。票据只存 SHA256 摘要。全局只允许一个活跃课堂连接；断线重连须重新取票据。

后续客户端消息均包含唯一 `event_id` 与 `type`。服务端消息公共字段为 `type/session_id/seq/at_ms`；`seq` 为当前连接序号，不是跨重连持久游标，`at_ms` 为场次开始后的毫秒数。

| 方向 | type | 关键内容 |
|---|---|---|
| 客户端→服务端 | `audio` | `audio`：Base64 PCM16，16 kHz 单声道；服务端限制实时发送速率 |
| 客户端→服务端 | `select_student` | `student_id`：`ming/yu/lin`，邀请当前举手学生 |
| 客户端→服务端 | `cancel`、`finish` | 打断或请求结束 |
| 客户端→服务端 | `playback_started` | `reply_id/latency_ms`；客户端延迟仅作初测 |
| 客户端→服务端 | `playback_done`、`playback_failed` | `reply_id`；只处理当前回复 |
| 客户端→服务端 | `vision_consent`、`image` | 分别为 `enabled` 布尔值、`image` Base64 JPEG |
| 客户端→服务端 | `pose` | `data`：`present/confidence/left_raised/right_raised/lean_degrees/center_x/movement`，无法判断保留空值 |
| 服务端→客户端 | `connected`、`ready` | 场次连接已建、识别会话就绪；不是同一阶段 |
| 服务端→客户端 | `speech_started`、`speech_stopped`、`partial` | VAD 变化及临时 `text` |
| 服务端→客户端 | `event` | `event:{id,session_id,type,at_ms,data}`，持久化事件（最终字幕等） |
| 服务端→客户端 | `raise`、`reply` | `student_id`；回复另带 `reply_id/text` |
| 服务端→客户端 | `audio`、`audio_end`、`cancel` | 带 `reply_id`；声音为 24 kHz PCM，结束消息含合成成功标志；取消后丢弃迟到块 |
| 服务端→客户端 | `listening`、`budget`、`ended`、`error` | 监听、预算、课堂收尾、错误；`ended` 不代表评课已生成 |

## 7. 数据、证据与费用

- `classrooms`：以原 `training_sessions.id` 为主键/外键，保存归属、状态、学生 JSON、报告和版本。旧登录、课程、训练记录与旧报告保持可读。
- `classroom_events`：场次事件，`(session_id,event_key)` 唯一；记录转写、学生、问题、动作、视觉、播放、异议等。
- `classroom_tickets`：票据摘要、归属、到期和单次使用状态。
- `classroom_api_usage`：服务、预算预留、实际估算、计量单位和状态；探针可没有场次编号。
- 六维为表达、节奏、互动、教态、提问、结构。资料引用不能单独证明教师做了某事；没有合格课堂事件引用则评分为 `null`，总分仅聚合有证据维度，显示覆盖数。
- 新真实报告校正重新请求模型，不固定加分。**旧 `/ai-review` 页面与旧 `/api/feedbacks/<id>/regenerate` 逻辑仍保留规则加分及失败后本地“已重写”提示，尚未移除。**旧页已有演示标签，但这仍是下次必须处理的真实性遗留项；不要在真实课堂验收中使用旧入口。
- 预算 100 元，不自动充值；80 元提醒，预计累计及在途达到 90 元停止新付费请求。未知失败保留预留；最近记录 0.0874 元为估算与预留之和，不是最终平台账单。
- 预算使用本机文件锁＋新数据库事务；活跃课堂和报告任务使用单进程协调。不能部署多个 workers、跨机器或多份工作目录共享数据库。
- `.env`、私有资料、证据图、调用记录、模型资源均在忽略范围；原始麦克风录音不落盘。Git 仓库不等于完整本机数据备份。
