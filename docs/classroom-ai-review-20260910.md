# 课堂 AI 评课：统一入口与证据可视化

日期：2026-09-10。范围：前端展示、导航与交互，不改变模型评分规则、课堂生成、数据库或既有报告内容。

## 阅读与导航

- 「历史课堂」中已结束的课堂进入 `/ai-review?classroom=<课堂编号>`；仍在授课的课堂进入 `/classroom?session=<课堂编号>`。
- 直接打开「AI 评课」时，读取最近的已结束课堂；没有记录时显示空态，不回退到演示数据。
- 课堂结束后保留“课堂已保存 / 查看 AI 评课”入口。不会自动离开授课页面，避免打断课后查看和设备清理流程。
- 历史报告选择器切换的是实际课堂报告。`sessionId`、`feedbackId` 和 `legacy=1` 保留旧训练报告入口，和真实课堂数据明确分开。
- 指定课堂不存在、无权限或读取失败时，不替换成另一份报告；编号无效时不发详情请求。

## 信息结构

| 内容 | 数据来源与边界 |
| --- | --- |
| 综合参考分 | 保存的 `overall_score`，不在浏览器重新算分；0–100 环形量程不是达标率或置信概率 |
| 六维教学剖面 | 保存的维度分数和原始理由；缺失值显示“暂不评分”，不填 0；横轴固定 0–100 |
| 课堂证据时间线 | 教师转写、学生生成、完整播放、视觉采样四条事件轨道；不是持续时间或教学质量的测量 |
| 证据抽屉 | 仅解析本节存在的事件编号，去重并按时间排列；支持搜索、原始 JSON 与鉴权截图 |
| 动作可观察性 | 保存的身体、手势、面部几何摘要，以可观察样本数 / 总样本数呈现；不推断心理状态 |
| 下一步练习 | 从有分数的维度中按分数升序取最多 3 项，展示固定复盘提示；显式标记“非新增 AI 结论” |
| 方法与来源 | 展示保存的资料、生成时间、版本和模型标识；历史未保存模型信息时明确标为未记录 |

分数不是经过人工校准的标准化量表，不提供排名、百分位、显著性或因果判断。不同证据覆盖的课堂不直接比较综合分。没有修改历史报告的原文，也没有将模板提示伪装成模型发现。

完整播放统计须匹配非空 `reply_id` 的学生生成记录，按回复去重，并排除失败、取消及打断记录。无法关联的播放事件仍在原始记录中保留，但不计入已完成次数。没有有效时间戳的事件只显示在列表，不补造 `0:00`；没有课堂时长时，图中明确说明横轴采用已知事件跨度。

## 状态与安全

- `insufficient` 显示全部缺项，不显示遗留分数或付费重试按钮。
- `running` 每 4 秒读取状态；页面隐藏时暂停请求，离开页面后清理计时器和在途详情请求。
- `failed` 可以保留旧报告，但显式注明“上一版，本次尚未成功”。
- 阅读、切换、打印都不触发评课生成。只有主动点击重评且确认费用提示后，才调用既有报告接口；预算仍由原后端管理。
- 不调用摄像头、麦克风、TTS、ASR，不读取生产密钥，不额外上报报告内容。报告页不初始化实时课堂设备通道。
- 所有文本使用 Vue 转义渲染；外部资料链接仅允许 HTTP(S)，以 `noopener noreferrer` 打开。无效引用显示警告，不补造证据。
- 证据截图关闭、切课或卸载后释放 Blob URL；迟到的截图响应不会重新打开窗口。
- 公共弹窗补充 Tab / Shift+Tab 焦点循环、Escape 关闭与触发按钮焦点恢复。

## 打印与复核

点击“打印 / PDF”，在浏览器打印窗口选择“另存为 PDF”。打印版包含全部六维原始结论及事件编号；自动展开方法、资料和动作边界，关闭打印后恢复折叠状态。PDF 含课堂信息，应按私人材料保存，不公开上传。

人工复核路径：选择维度 → 查看证据 → 核对转写、教师自纠及同一回复的播放状态 → 对照教学资料 → 必要时补充说明并确认重评。动作样本密度、入镜与检测成功率均不得直接视为授课能力。

设计采用已有 `frontend-ui-engineering`、`test-driven-development` 和 `documentation-and-adrs` 技能；已有技能足够覆盖本次前端报告，不另装通用报告生成插件，也不将私人课堂材料发送给外部报告服务。
