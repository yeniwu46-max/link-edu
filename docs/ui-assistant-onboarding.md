# 界面精简、数字人与新手导览

实施日期：2026-10-08。保持原有深色背景、紫橙配色、玻璃面板、动态背景及课堂评分规则。

## 页面与直接交互

- 登录后的课程、成长、评课、资源、知识库、个人中心和设置取消重复大标题，一级标题以读屏文本保留；工作台问候压缩为一行。
- 课程直接展示筛选和课程；成长直接展示复练与趋势；评课从课堂选择开始；资源保留分类与拖拽墙。历史评分来源保留在可展开说明中。
- 个人中心在侧栏之外的工作区居中，最大 1040px，采用主表单与成长摘要双栏；设置为均衡双栏，窄屏单栏。切换个人中心、设置和联系我们后内容回到顶部。
- 书册、档案、轨道和棱镜改为内容中的小型模型，没有旋转、展开、复位操作栏。横向拖动旋转、点击切换、双击复位；键盘左右键、Enter/Space、Home 对应同样操作。纵向触屏滚动与横向拖动分流，拖动后的点击被抑制。交互收敛后停止刷新。
- 手机顶部提供页面选择入口，数字人默认停靠页头，避免挡住课堂主屏和学生；打开底部对话面板时隐藏人物，关闭后恢复。全屏内仍可使用助手。

## 数字人与第三方来源

| 来源 | 用途、改编与许可 |

| [pixiv/three-vrm](https://github.com/pixiv/three-vrm) 3.5.5 | 固定版本，MIT。通过现有 Three.js 的 GLTFLoader/VRMLoaderPlugin 加载 VRM0；仅在人物进入可见区域后异步加载。保留完整依赖许可。 |
| [PolygonalMind/100Avatars / Olivia](https://github.com/PolygonalMind/100Avatars/tree/master/100Avatars_056) | 模型元数据为 CC0、Olivia 1.0。1,699,736 字节，本地部署；固定来源、SHA-256、作者记录在资产 SOURCE.md。调整手臂姿态、半身镜头、紫橙灯光、眨眼和头部状态。 |
| 项目现有 Three.js | 复用现有 WebGL 与材质体系，不增加第二套人物控制系统。运行时无需连接外部模型网站。 |

人物周围没有方框、底板或玻璃盒；模型失败、上下文丢失或 WebGL 不可用时显示同一 Olivia 模型渲染的透明 WebP 封面（10,142 字节）。

聆听、思考、回答及错误由文字状态与轻量姿态表示。口型使用实际播放音频的 RMS 幅度驱动 `aa` 表情，取消和播放结束停止；这是基础音频口型，并非中文音素级同步。正常渲染上限 30fps、DPR 上限 1.25；减少动态效果时关闭循环动作，隐藏或不可见时暂停；卸载释放场景、材质、纹理、渲染器与观察器。

本轮没有引入 TalkingHead 或 OpenAvatarChat。原有 Vue Bits、Kenney 等集成保持原许可与已有来源记录。

## 助手服务

入口：点击人物 → 使用帮助、文字问答，或主动点击“开始语音对话”。授权拒绝或服务不可用时，保留文字输入及本地 FAQ。问题记录必须由用户主动保存，仍走既有训练日志接口。

### 独立会话协议

- `GET /api/assistant/capabilities`：JWT 鉴权，返回文字/语音可用性、当前服务商与时限。
- `POST /api/assistant/ticket`：JWT 鉴权，`mode: text | voice`，签发 45 秒有效、单次使用的随机凭据；服务端只在内存保存摘要，新凭据替换同账号旧凭据。
- `WS /api/assistant/live`：凭据仅在首帧发送，不放 URL。服务器返回随机 `session_id`；每轮返回 `turn_id`。事件包括 `recognition`、`answer_delta`、`answer`（含来源）、`audio`、`audio_end`、`state`、`cancel`、`error`、`closed`。
- 用户语音停顿后提交；真实 ASR 的 speech-start 事件停止当前回答。客户端丢弃旧会话、已取消轮次及晚到音频，连接中的取消也会回收资源。
- 每会话最长 300 秒、连续静默 60 秒结束；正在播放回答不计为静默。每账号一个连接，全局最多五个连接，每会话最多 40 次提问。沿用单进程课堂部署方式。

### 数据与费用

复用当前 ASR/LLM/TTS 配置、费用预留及结算；没有变更服务商或费用上限。助手的成本记录不绑定课堂，不创建 Classroom/ClassroomEvent，不进入训练评分。问答上下文只保存在当前连接与页面内存，关闭后端连接后释放；用户仍可主动保存对话到训练日志。供应商处理语音和问题的事实在“语音与隐私”中说明。

系统使用回答依据统一功能说明，教学回答复用现有知识库检索，返回可展开的来源。最终来源 ID 必须来自本次候选集合；没有有效依据时返回无法确认提示。

功能说明的唯一维护源是 `backend/data/assistant-guide.json`；`scripts/sync-assistant-guide.mjs` 在前端 dev/build 前同步到 `frontend/src/data/systemGuide.json`，测试检查两份内容一致。更新说明需同时发布前后端。

关闭面板、退出登录、页面隐藏、开始或恢复课堂采集时停止助手麦克风、音频与连接；课堂进行中仅允许文字帮助。权限请求尚未完成时关闭页面，也会停止迟到的媒体流。

## 新手导览

按 `用户 ID + 导览版本` 写入浏览器本地记录。首次欢迎可以开始或跳过；助手与设置均可重新开始。八步依次介绍工作台、课程与模型、准备与授权、主屏与学生、AI 评课、成长复练、资源与知识库、设置与数字人。

导览只路由导航与展示，不勾选授权、不申请设备、不开始课堂。跨页等待目标加载，跟随滚动和窗口大小重新定位；目标缺失则显示居中提示卡。支持上一步、下一步、跳过、Escape、Tab 焦点约束与关闭后焦点返回；课堂进行中不弹出。

## 验证记录与限制

### 自动化

- 前端 `npm test`：170 项通过。
- 后端助手、课堂、providers、讯飞与 speech 相关测试：175 项通过。
- `npm run build` 生产构建通过。仍有现有 Three.js/图表公共包超过 500kB 的提示；数字人引擎独立异步包约 150.8kB（gzip 37.4kB），人物不阻塞首屏。
- 新增覆盖短期凭据、重放、账号隔离、取消、迟到音频、权限失败、关闭期间迟到媒体、时限、播放不计静默、断开资源释放、来源过滤、不写课堂记录、导览记录隔离与说明同步。

### 浏览器与合成媒体

在 1440×900、1280×720、768×1024、375×812 检查了核心界面；未发现文档级横向溢出。1440 宽个人中心实测宽 1040px，在工作区两侧余量约 77px。1280×720 课堂主屏、控制栏、三个学生均在首屏，学生区高 170px。手机页头数字人不覆盖主屏和学生。

模型点击切换、Home、双击复位已在浏览器操作；拖动防误触、纵向手势分流及边界约束有自动化覆盖。导览重看、跨页定位、跳过、无自动授权通过；旧版完整八步导览也已走通。WebGL 不可用时三个学生及 Olivia 正常显示图片回退。

本机单次采样（开发服务器，非生产性能保证）：

| 项目 | 实测 |
| --- | --- |
| Olivia 连续 10 秒 | 26.4fps；JS 更新及提交渲染平均 0.36ms/帧；1 个 geometry、3 张纹理。此数不包含独立 GPU 执行耗时。 |
| 人物隐藏 / 减少动态效果 | 10 秒测量期间新增帧数为 0。 |

| 合成录像 | 实际有效时长 8 秒（墙钟 10 秒中暂停 2 秒），2 段，1 条音轨，约 1.53MB；采样到 196 次学生帧，三席位均有非透明像素。 |

Chrome 在后台的一次录像测量只有 2.5fps，是后台节流结果，没有将它当作前台性能。前台整页采样 53.3fps 也没有达到早期提出的 55fps 目标，仍需在目标设备和生产构建下继续采样优化，不能宣称稳定 55/60fps。

### 真实服务与真实设备的区分

`scripts/assistant-live-smoke.py --live` 是显式选择的真实服务检查，会产生现有预算机制下的语音和模型用量。本次使用 2.86 秒合成提问 PCM，经过实际配置的讯飞 ASR → DeepSeek → 讯飞 TTS，识别、回答文本及回答音频均成功。单次总耗时 7.97 秒；发送完输入（含 2 秒静音尾帧）后 2.287 秒收到回答音频。这不是“说话结束后 2.287 秒”，也不是延迟分位数。

没有采集用户真实麦克风、摄像头或测量扬声器回声；真实设备的连续语音、说话打断和回声消除效果尚未验收。自动化中的断网、取消、超时、权限拒绝使用模拟故障；触屏滚动逻辑有测试，未在实体手机验证。验收夹具位于 frontend/tests，不进入生产入口。
