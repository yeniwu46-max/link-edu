# 课堂双布局与 Q 版助手 · 2026-10-22

> 本文是当日早期阶段记录。用户随后否决 3D 造型，当前角色已改为 2D 像素图集，坐席改为窄栏纵向排列。最终实现与最新验收见 [像素课堂与备课桌 UI](pixel-studio-ui-20261022.md)。下文的 3D 助手说明与测试数据仅记录历史状态。

课堂控制栏新增「默认布局 / 对话布局」。首次仍使用原布局，浏览器通过 `classroom-layout` 记住后续选择。对话布局桌面端左侧为当前课堂的完整对话，右侧为三名学生；700px 及以下改为学生在上、对话在下。

教师小窗默认在左侧右上方，桌面宽 240px、手机宽 160px。标题栏支持鼠标和触摸拖动，可跨左右区域；方向键每次移动 10px，Shift 加速至 40px，Home 或复位按钮恢复位置。位置只保留于当前页面，窗口和全屏变化会重新约束边界。

## 数据与生命周期

- 复用现有 WebSocket 语音与学生生成事件，前端独立维护展示记录，不增加后端 API 或数据库字段。
- 老师临时转写原位更新，定稿后归并。学生按 generation ID、reply ID 和事件 ID 归并，兼容正式事件先于回复到达，以及举手待回应后不带 generation ID 的回复。
- 失败、打断、断线留下明确标记的临时内容；同页重连保留，刷新与历史课堂只恢复服务端保存的证据。另一节课堂清空临时状态。
- 浏览历史时暂停跟随，使用「回到最新」恢复；布局、视频元素、学生 WebGL 场景与课堂连接相互独立，切换不重新采集媒体。录像继续使用原固定合成布局。

## Q 版客服助手

右下角形象改为本地 Three.js 几何构建的圆脸、耳麦、短身角色。保留眨眼、倾听、思考、随音量张嘴、轻微指针跟随及原聊天和拖动入口；授课中的安静模式与系统减少动态设置继续生效。隐藏时暂停绘制，卸载释放资源。WebGL 不可用或丢失时显示同模型渲染的透明 PNG 备用图。

模型位于 `frontend/src/components/fx/chibiAssistantScene.js`，无需新依赖、模型下载或纹理请求。旧 Olivia 文件保留以兼容历史材料，当前入口不再加载。
