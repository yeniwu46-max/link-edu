# 两路更新合并与上线文案整理

## 目标与边界

合并 `origin/gao/dev` 和用户提供的 `link-edu-main.zip`，保留本机现有模拟授课及证据评课功能。仅整理上线文案，不执行生产部署、数据库迁移、付费探针或远程推送。

## 顺序与验收

1. 保全：保存当前已实现的播放器、学生形象和 AI 报告改动；建立源码快照与授课保护清单。验收：本地可恢复的提交和文件备份均存在。
2. Git 更新：核对 `gao/dev` 与共同祖先差异，合并资源库、通用页面及相关素材。授课文件始终以本机为准，共享样式/路由必须保留授课例外。验收：保护清单文件散列不变，新增依赖和外部链接已检查。
3. 压缩包更新：隔离解压，过滤依赖、缓存、环境配置、数据库和 Git hooks；结合包内提交历史进行三方合并，不把旧文件覆盖为“新版本”。逐页验收登录、工作台、课程、旧评课、成长、资源、个人中心与帮助功能。
4. 文案：精简开发说明、重复引导和无功能入口，保留授权、预算、失败原因及证据不足/演示数据身份。验收：模拟授课零直接改动，功能性提示仍可见。
5. 回归：前后端测试、生产构建、浏览器页面巡检、模拟课堂与证据报告专项测试。验收：记录结果、冲突取舍和剩余上线限制，完成本地合并提交。

## 风险处理

- 压缩包包括旧课堂实现，禁止回退本机流式交互、动作识别、预算隔离和独立 AI 报告页。
- 工作区已有未提交成果和无关个人文件，先保存成果，个人表格和生成脚本不纳入产品提交。
- 不导入压缩包中的数据库、私有配置或依赖安装结果；仅使用当前配置与锁文件管理依赖。
- 入库教学资料保留来源；页面包装不得编造评分成效、机构背书或不可用能力。
