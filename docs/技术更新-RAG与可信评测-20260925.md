# 临客 LINK 技术更新说明（2026-09-25）

**版本标识：** `2026.09.25-rag`（见仓库根目录 `VERSION.json`）  
**Git 标签建议：** `v2026.09.25-rag`  
**适用范围：** 后端 `backend/rag`、课堂 AI 评课、前端知识库与证据互跳、离线 evals 规则扩展。

---

## 1. 更新摘要

在既有 **MySQL + BLOB 向量 + 进程内索引** 底座上（[ADR-004](decisions/004-rag-mysql-vector-store.md)），完成 RAG「纵深」能力与「可信生成 / 评测」闭环，并与模拟课堂六维报告、片段训练评课接口对齐。

| 主题 | 一句话 |
| --- | --- |
| 知识库 | 上传 → 解析 → 分块 → 向量 → 检索 / 问答 / 评课依据 |
| 检索增强 | BM25 + 向量 RRF、Top20 精排、问句改写 / HyDE、父子块、Graph 元数据 |
| 语料治理 | 版本、授权、失效日、审计日志、异步入库 |
| 可信 | 引用校验、可选 LLM Judge、无依据打分 / 错引用离线规则 |
| 产品 | 侧栏「知识库」页；AI 评课页 kb 原文 ↔ 课堂事件互跳 |

## 2. 新增功能

### 2.1 RAG 模块（`backend/rag/`）

- **HTTP：** `/api/rag/*`（文档 CRUD、retrieve、query、evaluate、status、audit、单切片 `GET /chunks/<id>`）
- **CLI：** `python -m rag.cli`（ingest / reindex / stats / query）
- **存储：** `kb_documents`、`kb_chunks`、`kb_audit_logs`；原文件 `RAG_STORAGE_DIR/files/`
- **混合检索：** `hybrid.py`（jieba + BM25Okapi + RRF，`RAG_HYBRID_ENABLED`）
- **精排：** `rerank.py`（bi-encoder，默认 Top20→Top5）
- **问句：** `query_rewrite.py`（术语扩展；`RAG_QUERY_REWRITE=hyde` 时 HyDE）
- **长文档：** `parent_chunks.py` → `extra.parent_summary` 写入 embedding
- **Graph 预留：** `graph_meta.py` → `extra.graph` 实体/关系
- **治理：** `governance.py`（审计、过期文档不参与检索）
- **异步入库：** `jobs.py` + 上传表单 `async=1` / `RAG_ASYNC_INGEST`

### 2.2 前端知识库

- 路由 **`/knowledge`**（`RagKnowledgeView.vue`、`services/rag.js`）
- 教师侧：上传、资料列表、切片预览、试检索

### 2.3 课堂报告 × RAG 六维

- `rag/report_evidence.py`：对 **clarity / pace / interaction / posture / questioning / structure** 分别 `evidence_for_indicators`
- 评课 prompt 注入 **`theory_by_dimension`** + 合并 `references`（JSON 卡 + `kb:<chunk_id>`）
- 报告 JSON 含 `theory_by_dimension`；校验剔除 **跨维度错引 kb**

### 2.4 可信生成与评测

- **`rag/judge.py`：** 引用片段对齐、可选 LLM 复核 `theory_status`（`/api/rag/evaluate` 传 `judge: true`）
- **`rag/generation.py`：** 问答未标注依据句 / 引用对不上 chunk → `insufficient_evidence`
- **`rag/evaluation.py`：** 评课结果规则 audit + 可选 Judge

### 2.5 证据 UX（AI 评课页）

- 维度「教学依据」→ **知识库原文**弹窗（`GET /api/rag/chunks/<id>`）
- **关联课堂事件** → 证据抽屉 / 时间线同源 `#review-evidence-<id>`

### 2.6 运维与评测资产

- 脚本：`scripts/rag_*`、语料 `sources/rag/`、`evals/rag_retrieval_golden.json`
- 文档体系：`docs/rag/`、`docs/rag-knowledge-base.md`
- pytest：`test_rag*.py`；evals：`test_rules_grounding.py`（无依据打分、错 kb 引用）

## 3. 优化与行为变更

| 项 | 说明 |
| --- | --- |
| `gather_report_references` | 由「全局 merge 5 条」改为 **按维检索 + 合并去重** |
| `validate_report` | 增加 `theory_by_dimension` 过滤 `kb:` 引用 |
| `relevant` 门控 | 混合检索下 **相似度用向量余弦** 对比 `RAG_MIN_SCORE`，RRF 仅排序 |
| 默认上传 | 生产默认 **异步入库**；测试 / 显式 `sync=1` 同步 |
| 课堂 JSON 依据 | 仍保留 BM25 `classroom_knowledge.json`，与向量库并存 |
| `classroom_reports.gather_report_references` | 内部优先 `report_evidence.gather_classroom_theory_evidence` |

## 4. 配置要点（生产）

见 `backend/.env.example` 与 [operations-runbook](rag/operations-runbook.md)。

```env
RAG_ENABLED=true
RAG_EMBEDDING_PROVIDER=openai_compatible
RAG_HYBRID_ENABLED=true
RAG_FETCH_K=20
RAG_RERANK_ENABLED=true
RAG_QUERY_REWRITE=expand
RAG_ASYNC_INGEST=true
RAG_ADMIN_ACCOUNTS=管理员账号
```

语义向量切换后必须：`python -m rag.cli reindex --all`。

## 7. 已知边界

- GraphRAG **跨文档图检索** 仍为 `extra.graph` 元数据，未单独图索引服务。
- `/api/rag/evaluate` 的 **LLM Judge 默认关闭**，需显式 `judge: true`（额外模型费用）。
- 竞赛交付包 `output/` 不随本版本自动更新，需单独打包。
