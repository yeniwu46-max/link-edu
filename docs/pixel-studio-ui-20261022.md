# 像素课堂与备课桌 UI · 2026-10-22

本轮最终角色方向为 **2D 像素小人**。先前的圆润 3D 原型已停止使用；三名学生和客服助手共用新的像素画风。课程备课桌、纸片标题、课堂双布局和原版 UI 切换保留。

## 角色交付与状态

- [四人正、侧、背三视图](design/20261022/pixel/turnarounds.png)是设计参考；运行资源为 `frontend/public/assets/characters/pixel/{ming,yu,lin,assistant}.png`，四份透明 4×3 图集，各 1.47–1.74 MB。
- 每人 12 个姿态，共 48 格。学生包含听讲、眨眼、阅读、书写、思考、举手、闭嘴回答、开口发言、点头、疑惑、开心和转头；助手包含待命、眨眼、聆听、思考、挥手、介绍、回答、发言、点头、疑惑、开心和转头。
- 图集采用内置 `image_gen` 生成，原始提示词与局部修订提示词保存于 [pixel 目录](design/20261022/pixel/)。这是姿态帧切换，不是连续骨骼动画。课堂运行时优先使用真实举手、生成、音频播放和失败状态；发言开口由实际音量决定。空闲时错开眨眼、看书和书写，点名短暂点头，回复完成短暂开心。未收到状态时不虚构课堂结果。
- 运行组件为 `PixelStudentStage.vue`、`DigitalHuman.vue`，共享图集裁切逻辑。学生仍用同一画布，保留每人录像快照；换布局不创建媒体或 WebSocket。不再依赖角色 WebGL/GLB。
- 右侧坐席宽 240–300px，纵向独立滚动；默认布局底部横排。手机每个滚动单元完整显示一席，教师小窗初始放在对话区内，可跨区拖动。
- 限制 30fps；减少动态时静态保留当前重要姿态，页面隐藏暂停，卸载关闭 ImageBitmap、取消帧循环与观察器。图集加载失败保留静态像素备用图和点名按钮。

可直接打开开发预览：`http://127.0.0.1:5188/tests/pixel-cast-browser.html`，点击 12 个按钮查看四人的姿态。该入口为本地开发夹具，不属于生产导航。

## 备课桌与 UI 保留

- 课程中心使用项目内的 `prep-desk.png`，十个物件区域可点击、高亮，旁边有真实文字按钮供键盘、触摸和读屏使用；搜索、分类、详情、进度、来源、慕课入口与全部课程目录保留。
- 新页面使用服务端课程 ID；`/training` 跳转保留 `courseId`，课堂准备页显示所选训练技能。后端场景仍为当前支持的「分数的初步认识」，本次没有扩展课程场景协议、自动开课或修改数据库。
- 图片加载失败仍能从文字目录选课，无 WebGL 也可操作备课桌。最新需求使用贴图，因此本次备课桌是可点击的图片场景，不是自由视角 Three.js 场景。
- 八个主页面共用真实文字的纸片标题，支持动态问候、长姓名、双主题、窄屏和减少动态。首页新 UI 的角色预览也使用同套像素图。
- 顶栏「UI 版本」可切换「备课桌版 / 原版界面」，浏览器键 `link-ui-version` 记住选择。原课程页完整保存在 `OriginalCoursesView.vue`，原版标题与页面风格通过开关恢复；修改前的源码快照位于 `docs/design/20261022/original-source/`。原有模型和素材仍保留。
- 被否决的本轮 3D 原型源文件保存在 `assets/source/characters/`，其运行资产与脚本模块归档于 `rejected-3d-runtime/`，当前页面不加载。旧 `characters-reference.png`、`model-previews/` 只作历史参考。
