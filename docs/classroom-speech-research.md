# LINK 实时试讲语音分析研究方案

建立日期：2026-11-06  
适用场景：教师使用 LINK 实时录制试讲，语音、视频和课堂事件按时间戳关联；建议在课后复核后生成。

## 目标与边界

语音模块分为三条不同任务，避免把“说了什么”“如何组织教学话语”和“声音听起来怎样”合成一个含混的情绪/教学分数。

1. **普通话 ASR**：输出教师转写、时间位置及可用的语音片段时长；保留教师人工更正。
2. **教学话语分析**：在转写和课堂上下文中识别可复核的话语行为，例如提问、邀请参与、追问理由、解释/示范、重述或承接学生观点、反馈、总结。初版标签是 LINK 研究操作定义，不宣称为正式 CLASS 编码。
3. **声学情绪线索**：仅描述感知到的声学正负向/激活程度等候选信号；与转写语义分开标注，并允许“不确定/不判断”。不能单独推断教师真实内在情绪、教学态度、学生理解或教学质量。

CLASS-Secondary 附录可组织“教学对话、反馈质量、分析与探究、教师敏感性”等教学观察问题；它不定义声学情绪类别或自动识别规则。最终建议必须同时关联时间点、原话/互动和课堂目标，动作与声学模型结果都只是辅助证据。

## 与现有 LINK 链路的对接点

项目已有实时 ASR provider（百炼/讯飞）、VAD 起止事件、最终转写事件、教师语音时长、学生智能体回应/播放事件和课后评课报告。代码入口主要在：

- `backend/services/classroom_speech.py`、`backend/services/classroom_providers.py`：ASR provider 适配。
- `backend/services/classroom_runtime.py`：转写事件、时间戳和课堂运行状态。
- `backend/services/classroom_reports.py`：基于事件证据生成和校验报告。
- `frontend/src/services/classroomAudio.js`：实时音频采集。

现有链路保存转写和语音时长事件，不等于已经保存可供离线 SER 训练的完整原始音频切片。声音情绪研究若需 PCM 窗口，需先明确录音授权、保存路径/保留期、访问权限和删除方式；优先在用户已同意保存的原始课堂录像上离线抽取，或只在本机实时计算特征摘要。不能将学生智能体合成语音作为真人学生情绪证据。

## 研究阶段

### 阶段 A：先定标注手册

每个语音片段采用同一课堂时间轴，分别标注：

- 转写文本及 ASR 是否需更正；
- 教学话语标签（可多标签）：问题、邀请/点名、等待、追问理由、解释/示范、承接/重述、反馈、总结；
- 语义态度（从原话判断）与声学感知（从声音判断）分栏；
- 声学感知可用维度量尺：正负向（负—中性—正）、激活程度（平静—激活），附“不确定”；不要把标签叫作教师真实情绪；
- 证据时间范围、人工标注者、置信/分歧和上下文备注。

两名标注者先独立标注一批课堂片段，修订定义和例子后再扩大标注；报告标签一致性（分类用 Krippendorff’s alpha/加权 kappa，连续维度用 ICC），并保留分歧样本，而非只给模型准确率。

### 阶段 B：分任务建基线

- ASR：AISHELL/WenetSpeech 基线与 LINK 中文试讲录音分开评估，报告 CER；按教师分组留出真实试讲测试集。
- 教学话语：先对 ASR 转写做句段/话轮分类，基线可从规则/词表和中文预训练文本分类器开始；按教师、课程和录制场次隔离训练/测试，报告每类 precision、recall、macro-F1。
- 声学情绪：先用 Praat/eGeMAPS 一类声学特征做可解释基线，再试中文 SER 模型；CNSCED/MCAE-SPPS 只做公开语料基线，最终必须用自愿、授权的 LINK 试讲标注集做外部验证。分类报告 UAR/macro-F1；连续 valence/arousal 可报告 CCC；增加低置信弃答与校准分析。

### 阶段 C：实时接入与教练输出

实时只做低延迟事件暂存和候选标签，不立即据情绪信号给教师下结论。结束课堂后结合转写、学生智能体回应（明确为模拟）、视频动作、课程目标和知识来源，生成：

```text
时间点 → 原话/互动证据 → 教学话语观察 → 声学线索（可选、带不确定性）
→ CLASS-S 相关观察维度 → 可尝试的下一次练习
```

只有真人学生录音/回应才能用于真人师生轮次分析；模拟学生回应单独标识。情绪模型不得给个人贴性格/心理标签，不作为教师绩效或淘汰决策依据。

## 首轮实验建议

### 当前代码接入（2026-11-06）

- ASR 确认的教师话轮会保存原话、话语候选标签及命中的词语线索。当前规则类别包括提出问题、邀请参与、追问理由、解释/示范、反馈/承接、总结/回顾。
- 麦克风 PCM 在浏览器 AudioWorklet 内提取约 200ms 一帧的 RMS 音量、过零率和粗略基频；只把数值特征送入课堂运行服务，不另存 PCM 音频。
- 转写确认后，特征按话轮聚合并与同一转写事件、课堂时间关联；报告证据抽屉分别呈现教学话语和声音表达线索。
- 规则匹配与声学描述都是候选证据。暂未接入经验证的中文 SER 模型，所以不会输出“积极/消极情绪”结论，也不把声音变化用于六维分数。
- 音量/基频会受麦克风距离、自动增益、背景噪声、个人音域影响；应回放核对，并以授权的人工标注数据验证后再决定是否训练SER模型。

1. 先抽取 10–20 份知情同意的 LINK 试讲，制作小型人工金标准；这一步只做研究数据准备，不把公开数据大规模下载进项目仓库。
2. 用现有转写链路做 ASR 错误核查；优先研究“教师提问—等待—追问/反馈”教学话语标签。
3. CNSCED 和 MCAE-SPPS 跑中文声学情绪基线；把测试教师严格按人隔离，观察跨说话人、录制设备和教室噪声下的性能差异。
4. 若公开情绪模型不能稳定迁移到试讲语音，保留声学统计和人工复核，不将情绪自动判断接入建议正文。
