# MM-TBA 动作证据与 CLASS-Secondary 观察框架

状态：LINK 试讲分析设计草案（证据组织与建议流程；不是 CLASS 正式实施或评分手册）  
适用对象：初高中教师试讲录像，包括 LINK 实时录制回放。  
建立日期：2026-11-06

## 纳入项目的来源

- 本项目已有 MM-TBA 动作检测流程和数据集工作副本：动作模型输出 Normal、Writing、Pointing 等标签及时间点。模型标签是行为候选证据，须抽查原始视频，不能直接当作教学质量判断。
- 纳入 MM-TBA 论文/数据集作为动作识别来源。项目中的分析脚本与输出见 `scripts/Run-MM-TBAChunkedAnalysis.ps1`、`scripts/Render-MM-TBAAnnotations.py`、`output/mm-tba/`；完整数据文件按项目 `.gitignore` 和数据许可处理，不在本说明中复制。
- 将用户提供的 `Upper Elementary/Secondary CLASS Manual Technical Appendix: Web Version` 归档于 `sources/references/CLASS-Upper-Elementary-Secondary-Technical-Appendix-2012.pdf`。该 2012 技术附录说明 Secondary（7–12 年级）框架、心理测量研究及观察流程。文件首页注明版权所有，保留所有权利；仅作为项目内部参考来源，不视为公开许可或完整 CLASS 手册。

## 两者如何联合

两者用途不同，按如下证据链联合：

```text
视频帧 / MM-TBA
  → 动作候选（Normal / Writing / Pointing …，含时间、置信度）
  → 人工抽查画面并保留核验状态
  → 同时间段教师转写、学生回应、课程目标与材料
  → 提出一个 CLASS-S 维度相关的观察问题
  → 依据互动证据形成可回放的改进建议
```

MM-TBA回答“画面中可能发生了什么动作”；CLASS-S提供“课堂互动中值得观察什么”。动作标签本身不决定 CLASS 维度表现，不得转换成 CLASS 分数或高低档。

## CLASS-S 观察目录

技术附录记载 3 个领域下 11 个维度，另有独立的 Student Engagement 维度（共 12 项）。以下仅作 LINK 的问题组织目录，中文为工作译名，不替代官方定义。

| 领域 | 维度 | 对录像/动作/转写的观察问题 |
|---|---|---|
| 情感支持 | 积极氛围 | 教师是否以尊重、积极的方式回应学生？结合语句和互动，不以微笑/声调单独判定。 |
|  | 消极氛围 | 是否出现可明确核验的负向、敌意或惩罚性互动？没有证据时不作负面推断。 |
|  | 教师敏感性 | 教师是否发现学生的学习或情绪信号并作出回应？需可见/可听的学生信号与教师跟进。 |
|  | 尊重学生观点 | 教师是否邀请、接纳并延展学生意见，提供适龄自主性？需对话或课堂互动证据。 |
| 课堂组织 | 行为管理 | 教师如何说明预期、维持活动秩序并回应干扰？动作模型不能独立判断。 |
|  | 学习效率 | 活动转换、板书、材料使用是否帮助课堂持续开展？结合视频、转写和课程流程。 |
|  | 教学学习形式 | 讲解、演示、板书、练习等是否让学习者有机会参与内容？动作只提供活动线索。 |
| 教学支持 | 内容理解 | 教师是否解释概念和联系、检查理解？需对齐课程内容、转写和学习者回应。 |
|  | 分析与探究 | 是否引导解释理由、推理、比较、探究或解决问题？需要问题和回应证据。 |
|  | 反馈质量 | 是否针对学习者回应给出具体跟进，帮助理解或改进？需完整互动话轮。 |
|  | 教学对话 | 是否形成连续且有意义的师生对话？需转写及学生回应，单向讲授音频不够。 |
| 独立维度 | 学生投入 | 学习者是否在当前活动中表现出参与？真人学生以视频/互动证据判断；LINK 智能体回答必须标注“模拟回应”，不能冒充真人投入。 |

## 动作类别的使用规则

| MM-TBA 标签 | 报告可写的事实 | 可辅助查看的 CLASS-S 维度 | 不可直接推出 |
|---|---|---|---|
| Normal | 模型在该采样时刻未识别到其他训练类别（以实际模型定义为准） | 仅作为视频定位线索 | “没有动作”“教师在听”“教学正常”或教学质量结论 |
| Writing | 模型检测到书写候选，给出时间点/置信度 | 学习效率、教学学习形式；结合讲解与学习者参与证据 | 板书清楚、节奏过慢/过快、学生理解或抄写情况 |
| Pointing | 模型检测到指向候选，给出时间点/置信度 | 教学学习形式、内容理解；核对指向对象、口头解释和后续检查 | 指向正确重点、有效讲解、学生注意/理解 |

如模型输出还含互动、节拍手势或描述性手势，先依据其数据集标签定义处理并抽样复核；不凭未验证标签扩展评分标准。

## 报告规则

每条建议以统一结构保存：

```json
{
  "focus_dimension": "instructional_learning_formats",
  "time_range_ms": [280000, 305000],
  "action_candidates": [{"label": "Writing", "confidence": 0.62, "review_status": "human_checked"}],
  "classroom_evidence": ["教师转写/学生回应事件引用"],
  "observation": "只描述已核实的课堂事实",
  "interpretation": "说明这些事实与观察维度的关联及不确定性",
  "practice": "给出可操作的下一次练习",
  "evidence_status": "supported | partial | insufficient"
}
```

- 动作和教学判断分层存储；事实证据与理论/框架依据分开引用。
- 视频动作节点可跳转回原始时间点；报告要能显示模型标签、置信度及人工核验状态。
- 没有转写/互动证据时，仍可呈现动作时间线，但教学解释写“待结合课堂内容核验”，不生成针对教师的缺陷结论。
- 没有学生画面或真实回应时，不评价真实学生投入；若使用 LINK 的学生智能体，明确标记为模拟回应。
- 不从面部、头部方向、手势或音高单独推断情绪、注意力、理解、动机或个性。
- 不输出 CLASS 1–7 分数、正式 CLASS 档位或“CLASS 评估结果”。避免复刻受版权保护的详细评分描述与观察手册。
