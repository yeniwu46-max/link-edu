# 课堂播放器 UI 改版任务

范围：统一训练入口、精简课堂文案、播放器式控制栏、替换用户提供的三组学生形象、学生语音 1.2 倍速。不改授权、预算、报告证据门槛，不实现录像，不自动提交或推送。

## 1. 入口与播放时序（先测试）

- `/training` 兼容跳转到 `/classroom`，旧演示不再作为授课入口；显式 8 分钟模式可保留，跳转不创建课堂、不打开设备。
- 音频以 1.2 倍速播放，连续 PCM 分块按加速后的长度排队；完成回执仍等待真实播放结束，失败/打断语义不变。
- 验证：路由、PCM 调度和完成回执单元测试。文件：入口 helper、main、音频服务及两个测试。

## 2. 学生形象

- 小明/小雨/小林分别使用紫衣/橙衣/蓝衣角色，各有听讲和举手两态；第 7 张用内置图片工具去掉灰白背景，其他五张保留原图 alpha。
- 角色呼吸、举手轻摆与发言波形均可通过减少动态效果关闭；保留流式气泡和 15 秒停留，不随内容改变主画面高度。
- 验证：状态映射测试、透明通道检查、浏览器听讲/思考/发言截图。

## 3. 播放器式课堂

- 收拢页头与授权条；未授权用一行提醒，故障保留具体原因和重试入口。
- 视频下沿固定控制栏：授课/暂停、音量、字幕、清晰度、设置、记录、全屏。图标有可访问名称及悬停/键盘提示。
- 固定视频与三学生区域，减少装饰文字；动效不驱动布局。设置/记录弹窗支持 Escape 和焦点返回。
- 验证：前端全测、构建，320/768/1024/1440 宽度与全屏浏览器验收。无真实设备、外网模型或业务写入。

## 交付检查

- 保留开始不可用原因、10 秒结束限制、摄像头单独预览和原有权限边界。
- 现有学生回复、报告、生命周期测试无回归。
- 记录图片来源、抠图提示词及变更边界；不把合成浏览器测试当真人声学验收。
