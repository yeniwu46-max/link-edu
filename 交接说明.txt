临客 LINK · 项目交接说明
========================

一、项目简介
-----------
AI 微格教学训练平台（师范生 / 指导教师）
- 首页：开场视频 + 品牌展示 + 登录页（苹果风玻璃质感）
- 工作台：训练数据总览、继续训练、AI 摘要、快捷入口
- 课程中心 / 教学训练 / AI 评课 / 成长档案 / 资源库：可演示闭环
- 点击特效：全站 ClickSpark；内页锐角 + 局部特效

二、技术栈
---------
前端：Vue 3 + Vite + Pinia + Naive UI + GSAP
      + motion-v / vue-echarts / @number-flow/vue / @vueuse/core / wavesurfer.js
后端：Flask + SQLAlchemy + JWT
数据库：MySQL 8（PyMySQL）

三、目录结构
-----------

│   ├── public/assets/ 图片与视频素材

四、环境要求
-----------
- Node.js 18+
- Python 3.10+
- MySQL 8（本机安装 或 Docker）

五、快速启动
-----------
1. 启动 MySQL，创建数据库 link（或使用 docker compose up -d）
2. 双击「启动后端.bat」（首次会自动装依赖、初始化数据库）
3. 双击「启动前端.bat」（首次会自动 npm install）
4. 浏览器打开 http://127.0.0.1:5188

演示账号：demo / link123

演示路径：登录 → 工作台 → 课程中心选课 → 教学训练 8 分钟 → 结束生成 AI 评课 → 成长档案看走势

六、手动启动（命令行）
--------------------
【后端】
  cd backend
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  copy .env.example .env
  按本机 MySQL 密码修改 .env 里的 DATABASE_URL
  python init_db.py
  python app.py

【前端】
  cd frontend
  npm install
  npm run dev

七、主要 API
-----------
POST /api/auth/login                 登录
POST /api/auth/register              注册
GET  /api/auth/me                    当前用户（需 JWT）
GET  /api/dashboard/overview         工作台数据（需 JWT）
GET  /api/courses                    课程列表（含进度）
GET  /api/resources                  资源列表
POST /api/training/sessions          开始训练
PATCH /api/training/sessions/:id     更新进度
POST /api/training/sessions/:id/complete  结束训练并保存演示结果
POST /api/training/sessions/:id/ai-review  使用 DeepSeek 生成真实 AI 评课
GET  /api/feedbacks                  评课历史
GET  /api/growth?range=all|7d        成长轨迹
GET  /api/health                     健康检查

九、配置说明
-----------
backend/.env（从 .env.example 复制，本压缩包不含真实 .env）：
  DATABASE_URL=mysql+pymysql://root:密码@127.0.0.1:3306/link?charset=utf8mb4
  JWT_SECRET_KEY=请修改为随机字符串
  DEEPSEEK_API_KEY=你的 DeepSeek API Key（只放后端）
  DEEPSEEK_MODEL=deepseek-v4-flash
  DEEPSEEK_REASONING_EFFORT=high

前端代理已配置：/api → http://127.0.0.1:5000

十、注意事项
-----------
- 压缩包内不含 node_modules、.venv、dist、.env，解压后需重新安装依赖
- 视频素材较大，解压可能需要几分钟
- MySQL 密码请按本机环境修改 backend/.env
- 本机 MySQL 若使用 caching_sha2_password，需已安装 cryptography（已写入 requirements.txt）
