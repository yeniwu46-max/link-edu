# 公开教学资料索引（摘要）

> **用途**：把可核验公开来源集中在一页，便于备课与评委查阅。  
> **性质**：链接索引；**不转载**原文，**不授予**训练数据许可。  
> 核对日期口径见项目 `docs/classroom-sources.md`。

## 使用边界

- 可公开观看 ≠ 可复制进产品当全文，≠ 可用于模型微调。  
- 院校案例 PDF、用户提供 DOC 等私有附件不在本页展开。  
- 临客自编知识卡/教案仅供实训，须与上表公开链接区分标注。
