# 开课设备与授权检查清单

> **用途**：进入 `/classroom` 前的训前检查（临客整理）。  
> **性质**：产品操作建议，非正式国标。

## 检查项

- [ ] 浏览器允许本页使用**麦克风**（语音评课授权已勾选）
- [ ] 浏览器允许**摄像头**（正式课堂需要摄像；授权已勾选）
- [ ] 如需复盘，开课前勾选**本机录像**（默认关闭；不上传云端）
- [ ] 云端截图分析另有开关，未需要则保持关闭以控制费用
- [ ] 耳机/外放已试听，避免啸叫；环境噪声可接受
- [ ] 网络稳定；勿同时开多个课堂后端进程
- [ ] 已阅读本节课题知识卡或教案，明确平均分/同一整体目标

## 开始授课前

- [ ] 能力状态无阻断（对话/语音等提示已处理）
- [ ] 倒计时与模式（完整/片段）符合本次练习

做不到的项如实记录，不要为了演示删失败场次。
