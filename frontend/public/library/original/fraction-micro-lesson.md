# 《分数的初步认识》8–10 分钟微格教案样例

> **用途**：师范生片段教学备课模板（临客自编样例）。  
> **性质**：训练用教案结构，**不是**某版教材配套教案全文，**非正式国标**。  
> **课题**：小学数学 · 分数的初步认识（平均分与单位分数入门）

## 基本信息

| 项 | 内容 |
|----|------|
| 时长 | 8–10 分钟片段 |
| 目标 | 初步理解平均分；能表示 \(\frac{1}{2}\)、\(\frac{1}{4}\)；知道比较要基于同一整体 |
| 准备 | 圆形/方形纸片、简易板书区、可点名虚拟学生 |

## 过程时间分配

| 环节 | 建议分钟 | 要点 |
|------|----------|------|
| 导入 | 1 | 出示“分月饼/分纸片”情境，引出“怎样分才公平” |
| 新授·平均分 | 3 | 操作→口述→板书“平均分成…份” |
| 新授·单位分数 | 2 | 写出 \(\frac{1}{2}\)、\(\frac{1}{4}\)；学生指图说意义 |
| 比较与追问 | 2 | 同一整体比 \(\frac{1}{3}\) 与 \(\frac{1}{4}\)；追问不同整体 |
| 小结 | 1 | 回扣：平均分 → 份数关系 → 同一整体 |

## 板书结构示意

```
课题：分数的初步认识
---------------------------------
平均分：每一份同样多
  例：○ 分成 2 / 4 份

单位分数：1/n
  1/2    1/4

注意：比较要在同一整体上
```

## 提问与点名脚本（可直接用于临客课堂）

1. **点名小明**：“请指着图说，什么叫平均分？”  
2. **点名小雨**：“\(\frac{1}{4}\) 表示把什么平均分成几份？这一份是什么？”  
3. **全班后追问**：“\(\frac{1}{3}\) 和 \(\frac{1}{4}\)，在同一张纸上谁表示的份更小？为什么？”  
4. **深化**：“如果两张纸大小不一样，还能直接比谁的一份更大吗？”  
5. **续答口令**：学生被打断后，可说“请小雨继续刚才的想法”。

## 自评对照（六维提示，非正式打分表）

- **结构**：是否按平均分→分数→同一整体推进  
- **提问**：是否有点名 + 至少一次追问  
- **表达**：是否避免“随便分也是二分之一”类口误；若口误是否当堂纠正  
- **节奏**：提问后是否留出等待
